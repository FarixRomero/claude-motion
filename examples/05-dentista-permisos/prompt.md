# Prompt del usuario

Crear un proyecto con mi voz y una voz femenina sintética genérica para un diálogo
entre un paciente que pide una cita y una asistente que evade la solicitud, pero
ejecuta un borrado de usuarios. Usar `prompt-escenas-blocky.txt`, con personajes
de bloques, fondo oscuro con cuadrícula, ventana de interfaz, contadores y
subtítulos sincronizados. Voz a 1,2×, sin zumbido.
